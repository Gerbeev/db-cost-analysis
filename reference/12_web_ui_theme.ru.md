# Тема веб-интерфейса (обязательно для `webapp/static/`)

Веб-интерфейс аудита поддерживает **светлую** (токены по умолчанию в `:root`) и **тёмную** (`[data-theme="dark"]` в `app.css`) темы. При изменении стилей держите обе темы согласованными с этим описанием.

## Тёмная тема - «true black» (эталонная палитра)

Тёмный режим следует боковой панели в стиле ChatGPT: чисто чёрный фон, светло-серый текст, угольно-серые наведение/выделение. Не возвращайте сине-сланцевые фоны, пока этот документ не обновлён.

| Токен | Hex | Применение |
|-------|-----|-----|
| `--bg`, `--panel` | `#000000` | Страница, верхняя панель, карточки |
| `--panel-2` | `#212121` | Наведение, активный пункт навигации/боковой панели, приглушённые заливки |
| `--border` | `#2f2f2f` | Разделители и поля ввода (тонкие; лучше отступы, чем жирные рамки) |
| `--text` | `#ececec` | Основной текст и ссылки по умолчанию |
| `--muted` | `#b4b4b4` | Подписи, подсказки, иконки |
| `--accent` / `--accent-soft` | `#ececec` / `#212121` | Выделение без яркого фирменного синего |
| Основная кнопка | `#ffffff` на `#000000` | Главное действие; наведение `#e5e5e5` |
| `--radius` | `8px` | Строки списков, карточки, элементы управления (скруглённые «пилюли») |
| `--shadow` | `none` | Без теней на тёмных поверхностях |

Семантические цвета статусов (`--ok`, `--warn`, `--bad` и варианты `*-soft`) остаются зелёным/янтарным/красным, но с **тёмными** мягкими фонами, чтобы читаться на чёрном.

Полосы прокрутки (WebKit): тонкий бегунок `#3f3f3f` на чёрной дорожке.

## Светлая тема

Без изменений: светло-серая страница (`#f6f7f9`), белые панели, синий акцент (`#2563eb`). Светлые токены трогайте только для исправления контраста или доступности.

## Правила для разработчиков и агентов

1. **Единый источник токенов** - тёмные цвета живут в `[data-theme="dark"]` в `app.css`; избегайте жёстко заданных hex в `app.js`, кроме временного UI.
2. **Активное/наведение в тёмной теме** - используйте `var(--panel-2)`, а не синий `accent-soft`.
3. **Ссылки в тёмной теме** - цвет ссылки по умолчанию `--text`, не синий.
4. **Новые компоненты** - должны правильно выглядеть в обеих темах, используя только CSS-переменные.
5. **Изменение тёмного вида** - обновляйте этот файл и `app.css` в одном изменении.

## Где в интерфейсе

Переключатель **☀ / ☾** в правом верхнем углу; выбор сохраняется в `localStorage.theme`. Рядом - переключатель языка **EN / RU** (`localStorage.lang`).

## Файлы

| Файл | Роль |
|------|------|
| `webapp/static/app.css` | Токены темы и разметка |
| `webapp/static/app.js` | `data-theme` на `<html>` |
| `webapp/static/index.html` | Раннее чтение темы (без мигания) |
