# Синтетическая демонстрация - не финансовые данные компании

**ВНИМАНИЕ: SYNTHETIC_ONLY**. Все значения, ID, даты, ресурсы и кажущийся рост в апреле 2026 в этих файлах выдуманы только для демонстрации работы разбора и отчётов офлайн. Это не наблюдения о каком-либо реальном аккаунте Azure/Databricks.

В интерфейсе: **Аудиты → Открыть демо на синтетических данных** создаёт аудит `demo-synthetic`, в котором оба файла уже на месте (выгрузка в шаге 01, результат SQL 2.2 в шаге 02), так что можно попробовать каждый инструмент и расчёт.

Ожидается: два независимых регистра (Azure Actual в EUR; оценка Databricks по прайсу в USD) с помесячными сравнениями и файлами драйверов март/апрель. Синтетические данные намеренно показывают скачок март/апрель для проверки. **Не** объединяйте их и не переносите синтетические наблюдения в RCA. Созданное содержимое `audits/demo-synthetic` - приватные рабочие данные, Git их игнорирует.

`SYNTHETIC_report_example.md` - пример выходного отчёта анализатора; он генерируется инструментом и не переводится.
