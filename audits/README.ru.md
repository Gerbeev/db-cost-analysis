# Аудиты

Одна папка на аудит, создаётся в веб-интерфейсе (**Аудиты → Управление аудитами проекта**). Содержимое **не попадает в git** (данные биллинга, ID, имена) - храните в месте с контролем доступа; маскируйте перед передачей.

- Статус аудита показан на каждой странице шага; `audits/<audit-id>/STATUS.md` перегенерируется после каждого изменения.
- `_settings.json` - настройки интерфейса (хост / warehouse Databricks; никогда не токен). Может быть закоммичен (см. `.gitignore`). `_logs/` и `_trash/` внутри аудита - временные и остаются игнорируемыми.
- Удаление аудита: список **Аудиты** или **Обзор** аудита → **Удалить аудит** (удаляет папку `audits/<id>/`).
- `demo-synthetic/` - демо-аудит на синтетических данных (Аудиты → Открыть демо); удаляется как любой аудит.
