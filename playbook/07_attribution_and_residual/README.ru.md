**Цель:** у каждой единицы Δ есть владелец, либо она явно отмечена как необъяснённая; мост дельты сходится.
**Входные данные:** G6 пройдена. **Где работать:** `audits/<id>/delta_bridge.csv`, `audits/<id>/07_attribution_and_residual/`.

## Что сделать

| # | Действие | Источник | Куда сохранить |
|---|---|---|---|
| 7.1 | Владелец каждого драйвера CONFIRMED / LIKELY (владелец workspace, владелец задачи, теги `owner`, `cost_center`, `application`) | карточки драйверов, `sample_run_as` из `5.3`, теги | колонка `owner` в `delta_bridge.csv` |
| 7.2 | Общие ресурсы: распределять только по доказанному ключу (доля использования, байты, число запросов); иначе `SHARED_UNALLOCATED` | ресурсы Azure, метрики | `results/shared_allocation.csv` + строка `SH-01` |
| 7.3 | Неатрибутированная / без тегов Δ Databricks | `05_databricks_decomposition/results/5.5_attribution_coverage*.csv` | `notes.md` |
| 7.4 | Δ вне охвата (сервисы, не связанные с Databricks) | корзины шага 04 | строка `OOS-01` |
| 7.5 | Остаток: `UNX = TOTAL - Σ(ACCOUNTING + ROOT_CAUSE + SHARED_UNALLOCATED + OUT_OF_SCOPE)` | расчёт 7.5 в интерфейсе | строка `UNX` + доли |

Тождество моста (проверяется автоматически): `TOTAL = Σ ACCOUNTING + Σ ROOT_CAUSE + SHARED_UNALLOCATED + OUT_OF_SCOPE + UNEXPLAINED`. Строки `BUCKET` и `DRIVER_CANDIDATE` справочные и не учитываются.

## Автоматические проверки

- Тождество моста с точностью 1% от TOTAL.
- `UNEXPLAINED` ≤ 10% от TOTAL (R4). Если больше: продолжайте шаг 06 или отметьте C7.6 `[!] | accepted by <owner>`.

## Контрольная точка G7

Мост сходится; UNEXPLAINED ≤ 10% или явно принят владельцем аудита.
