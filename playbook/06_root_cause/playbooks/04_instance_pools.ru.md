# PB-POOLS - пулы инстансов

<!-- plain -->
> **Обзор.** Используйте, когда выросла стоимость **виртуальных машин**, а DBU нет. Простаивающие машины, удерживаемые в пуле инстансов, стоят денег за VM и не видны в потреблении Databricks.
<!-- /plain -->

**Сигналы:** стоимость VM Azure ↑ в managed RG при неизменных DBU; есть пулы (`worker_instance_pool_id` в `6.06`).

| # | Проверка | Источник | Что смотреть |
|---|---|---|---|
| P1 | Наблюдаемые часы простоя vs размещения по пулу/месяцу | [`6.08_pool_idle.sql`](../sql/6.08_pool_idle.sql) | `observed_idle_hours` ↑ |
| P2 | Конфигурация пула | Compute → Pools → min idle, max capacity, автоотключение простаивающих; аудит `6.14` (сервис `instancePools`) | Min idle ↑ на дату начала |
| P3 | Счётчики VM для типов узлов пула | Cost Analysis по Meter / Resource | Часы VM ↑ |

| ID | Механизм | Подтверждает | Опровергает |
|---|---|---|---|
| H-POL-01 | Увеличен min idle | Изменение конфигурации/аудит ≈ начало; часы простоя ↑ | Часы простоя не изменились |
| H-POL-02 | Увеличено автоотключение простаивающих инстансов | Более длинные интервалы READY | Длина интервалов не изменилась |
| H-POL-03 | Новый пул | Пул впервые появился ≈ начало | Был в B |

**Варианты исправления:** min idle = 0 вне рабочих часов; более короткое автоотключение простоя; объединение пулов.
