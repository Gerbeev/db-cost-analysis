# PB-NETWORK - сеть

<!-- plain -->
> **Обзор.** Используйте, когда выросла категория **NETWORK**: данные ходят между регионами, новый private endpoint, трафик через NAT или firewall.
<!-- /plain -->

**Сигналы:** счётчики Bandwidth, NAT Gateway, Private Link, Azure Firewall, VPN/ExpressRoute ↑.

| # | Проверка | Источник | Что смотреть |
|---|---|---|---|
| N1 | Разбивка счётчиков: часы vs обработанные ГБ | Cost Analysis по Meter, Resource | Фиксированная часть vs зависящая от объёма |
| N2 | Направление и регион | Имена счётчиков (межрегиональный, интернет-egress), `source_region`/`destination_region` в usage для serverless networking | Межрегиональные потоки |
| N3 | Новые сетевые ресурсы | Activity Log; дата первого выставления ресурса | Новые NAT/PE |
| N4 | Нагрузка за трафиком | Объекты `5.3` с началом ≈ начало сетевого роста; получатели Delta Sharing | Связанная задача |

| ID | Механизм | Подтверждает | Опровергает |
|---|---|---|---|
| H-NET-01 | Межрегиональная передача данных | Межрегиональные счётчики ↑; нагрузка читает удалённый регион | Без изменений |
| H-NET-02 | Обработка данных NAT gateway | ГБ, обработанные NAT ↑ | Без изменений |
| H-NET-03 | Обработка Private Link / новые endpoint | Часы или ГБ PE ↑ | Без изменений |
| H-NET-04 | Интернет-egress / обмен данными | Счётчики egress ↑; получатели sharing ↑ | Без изменений |
| H-NET-05 | Обработка в Firewall | ГБ Firewall ↑ | Без изменений |

Общие сетевые ресурсы: распределять только по доказательствам (шаг 7), иначе `SHARED_UNALLOCATED`.
