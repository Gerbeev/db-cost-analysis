# PB-SQL - SQL warehouses

<!-- plain -->
> **Обзор.** Используйте, когда дороже стал **SQL**: размер warehouse больше, больше кластеров, warehouse перестал останавливаться (изменили автоостановку) или больше или тяжелее запросов от дашборда или инструмента.
<!-- /plain -->

**Сигналы:** продукт `SQL` ↑ (классические, pro или serverless SQL SKU); `5.3` объекты `WAREHOUSE` ↑.

| # | Проверка | Источник | Что смотреть |
|---|---|---|---|
| S1 | История конфигурации warehouse | [`6.09_warehouse_config_history.sql`](../sql/6.09_warehouse_config_history.sql) | Изменения размера, типа, min/max кластеров, auto-stop |
| S2 | События жизненного цикла и масштабирования | [`6.10_warehouse_events.sql`](../sql/6.10_warehouse_events.sql) | Больше запусков, дольше RUNNING, больше SCALED_UP |
| S3 | Объём запросов, длительность, байты, spill | [`6.11_query_trends.sql`](../sql/6.11_query_trends.sql) | Запросы ↑, p95 ↑, прочитанные байты ↑ |
| S4 | Клиентские приложения / пользователи | [`6.12_query_clients.sql`](../sql/6.12_query_clients.sql) | Новый BI-инструмент / service principal / опрос |
| S5 | Стоимость warehouse B vs C, по дням | `5.3`, `5.4` | Дата начала по каждому warehouse |

| ID | Механизм | Подтверждает | Опровергает |
|---|---|---|---|
| H-SQL-01 | Увеличен размер или максимум кластеров | Изменение SCD2 ≈ начало; стоимость/час ↑ | Конфигурация не менялась |
| H-SQL-02 | Auto-stop увеличен / выключен | `auto_stop_minutes` ↑; периоды RUNNING удлиняются без роста запросов | Auto-stop не менялся |
| H-SQL-03 | Волна обновлений BI / опроса | Запросы ↑ от одного `client_application`; регулярные интервалы; warehouse работает ночью | Состав клиентов стабилен |
| H-SQL-04 | Регрессия запросов | p95 длительности / прочитанные байты / spill ↑ при стабильном числе запросов | Метрики на запрос стабильны |
| H-SQL-05 | Новый warehouse | Объект warehouse `NEW` | Был в B |
| H-SQL-06 | Миграция Classic/Pro → serverless | Классический SQL ↓, serverless SQL ↑ для тех же ID warehouse | Нет смены SKU |
| H-SQL-07 | Больше пользователей | `active_users` ↑ | Стабильно |

**Варианты исправления:** auto-stop 5-10 мин для serverless; подбор размера; ограничение максимума кластеров; расписания дашбордов / кэширование результатов; оптимизация запросов.
