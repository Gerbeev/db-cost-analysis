# PB-RATE - тарифы и учёт

<!-- plain -->
> **Обзор.** Используйте для эффектов шага 03: изменение цены, закончившееся обязательство или кредит, изменение курса. Это не про нагрузку, поэтому доказательства лежат в данных биллинга и договорах, а не в Databricks.
<!-- /plain -->

**Сигналы:** шаг 3 нашёл неоперационные эффекты; начало роста 1-го числа месяца; Actual ≠ Amortized; проверка направления R8 не пройдена.

| ID | Механизм | Подтверждает | Опровергает |
|---|---|---|---|
| H-RAT-01 | Покупка резервирования / savings plan отражена в Actual | `ChargeType = Purchase` в C; Amortized без изменений | Нет строк покупки |
| H-RAT-02 | Покрытие обязательств истекло или исчерпано (пул RI / SP / DBCU) | `PricingModel` смещается Reservation → OnDemand; счётчики DBU, показывавшие нулевую on-demand стоимость, пока действовал пул DBCU, теперь показывают затраты; остаток плана DBCU 0 / истёк (Портал → Reservations) | Структура моделей цены не изменилась; остаток DBCU есть |
| H-RAT-03 | Кредиты истекли / уменьшились | Строки кредитов из B отсутствуют в C; остаток кредитов в биллинговом профиле | Кредиты не менялись |
| H-RAT-04 | Изменение договорной скидки | `EffectivePrice` ↑ на дату договора; прайс Databricks без изменений | Фактическая цена не изменилась |
| H-RAT-05 | Изменение прайс-листа | [`3.1_list_price_history.sql`](../../03_accounting_effects/sql/3.1_list_price_history.sql) новая версия цены ≈ начало; ценовой эффект в `5.1` | Нет новой версии |
| H-RAT-06 | Изменение курса | Валюта счёта ≠ валюта прайса; смена курса на границе месяца | Та же валюта или стабильный курс |
| H-RAT-07 | Расширение охвата | Новая подписка / workspace впервые выставлены в C | Тот же список охвата |
| H-RAT-08 | Дублирование выгрузки | Повторяющиеся ID запусков / перекрывающиеся снимки; итог выгрузки > Cost Analysis | R6 пройдена |
| H-RAT-09 | Поздняя корректировка / пересчёт | Перевыгрузка отличается; всплеск `RETRACTION`/`RESTATEMENT` | Стабильно |
| H-RAT-10 | Только календарный эффект | Δ в сутки ≈ 0 | Δ в сутки > 0 |
| H-RAT-11 | Смена уровня workspace Standard → Premium (автоапгрейд 1 окт 2026) | Цена за единицу DBU растёт ступенькой в один день при неизменном количестве; имена SKU меняются `STANDARD_*` → `PREMIUM_*`; свойства workspace / Activity Log показывают смену уровня | Workspace уже был Premium в B |

**Варианты исправления:** продлить/изменить обязательства; согласовать отражение покупок в отчётах (Amortized для операционных KPI); исправить конвейер выгрузки.
